# 하단 안내 글꼴과 모바일 카테고리 — 2026-10-29

## 변경 내용

- 하단 이용 안내·이용규칙·개인정보 안내·문의하기·계정/안전 설정을 12px, 굵기 400으로 통일했다. 링크 줄 간격은 4px, 항목 간격은 14px다.
- `.service-footer a` 로고 스타일을 `.service-footer > a`로 제한했다. 로고는 기존 21px/800을 유지하고 안내 링크에 로고 글꼴이 적용되지 않는다.
- 모바일 카테고리의 가로 스크롤을 제거하고, 전체와 9개 취향 카테고리를 5개씩 두 줄, 지식·콘텐츠 연구소·함께 만드는 크루를 마지막 한 줄로 배치했다.
- 카테고리 이름은 잘라내지 않으며, 좁은 화면에서는 긴 이름을 줄바꿈한다. 선택 상태, 아이콘, 키보드 포커스와 기존 선택 동작을 유지했다.
- PC의 왼쪽 카테고리 메뉴와 상단 메뉴 구성은 유지했다.

## 검증 범위

소스 변경은 CSS 세 파일과 카테고리 버튼의 마크업이다. 데이터·API·회원·권한·결제 코드는 변경하지 않았다. 별도의 구현 복제 테스트는 추가하지 않고 형식·타입 검사와 실제 브라우저 화면을 확인한다.

로컬 Chrome에서 확인한 결과:

| 화면            | 폭                      | 결과                                             |
| --------------- | ----------------------- | ------------------------------------------------ |
| 공통 하단 안내  | 1,440px / 393px / 320px | 12px/400, 5개 링크 주소 유지, 로고 21px/800 유지 |
| 홈의 하단 안내  | 1,440px                 | 12px/400                                         |
| 홈 카테고리     | 393px / 360px           | 13개 항목, 5·5·3의 세 줄, 높이 184px             |
| 홈 카테고리     | 320px                   | 긴 이름 포함 13개, 높이 약 189px                 |
| 이야기 카테고리 | 393px                   | 같은 세 줄 배치                                  |

- 카테고리 영역에 내부 가로·세로 스크롤이 없고 모든 버튼이 영역 안에 있다.
- 카테고리 버튼은 가로·세로 최소 44px를 유지한다. 하단 안내 링크의 모바일 터치 높이 36px도 유지한다.
- 여행·콘텐츠 연구소·전체를 선택해 URL 필터와 선택 표시가 갱신되는지 확인했다.
- 테스트는 새 비회원 브라우저 컨텍스트를 사용하며 변경 API는 차단한다. 실제 휴대폰 조작 검증은 포함하지 않는다.

## 운영 반영

https://sliper.kr 에 반영했다. 최종 릴리스는 `20261029-footer-category-01`이다.

- 운영 Linux 빌드·서버 추적 manifest 117개 검사 통과, 오류 0개.
- standalone 3,159개 파일에서 금지 파일·허용하지 않은 링크 0개.
- 운영 미리보기와 실제 도메인에서 각각 8개 화면 시나리오 통과, 페이지 JavaScript 오류 0개.
- 웹 서비스만 교체했으며, 알림·영상 워커 PID를 유지했다. Sliper 감시와 기존 사이트는 HTTP 200이다.
- DB·환경 설정·광고/결제 활성화는 변경하지 않았다.
- 검증 원본은 Git 제외 `.local/footer-category-qa-local`, `.local/footer-category-qa-preview`, `.local/footer-category-qa-production`에 있다.
