# 게임 카드 탐색과 호스트 방 생성 (2026-10-31)

## 구현 범위

사용자 선택에 따라 새 게임 규칙은 추가하지 않고 기존 네 게임의 선택 경험을 먼저 개선했다. `/games`의 게임 종류 드롭다운을 제거하고 커버 카드 → 상세 소개 → 방 설정으로 이어지는 구조로 변경했다. 방 생성·참가·실시간 게임 API와 게임 규칙, DB·인증·미디어 설정은 유지한다.

- 카드에는 게임별 코드 기반 커버, 장르, 이름, 요약, 취향 태그, 참가 인원과 상세 보기 진입점을 표시한다. 참가 인원은 호스트를 제외한 기존 규칙 기준이다.
- 이름·설명·장르·태그로 검색하고 장르별로 필터링한다. 검색/필터는 메모리에 있는 정적 목록을 사용해 DB/API 요청을 추가하지 않는다. 검색 결과가 없으면 전체 목록으로 복구할 수 있다.
- 카드를 선택하면 같은 페이지에 상세 소개와 해당 게임의 방 설정을 연다. 별도 모달에 설정을 가두지 않는다. 소개의 ‘이 게임으로 방 만들기’는 설정 제목으로 바로 이동하며, ‘다른 게임 고르기’는 목록으로 돌아간다.
- 모바일은 두 열 카드와 한 열 상세/설정, 넓은 PC는 네 열 카드와 두 열 상세/설정을 사용한다. 키보드 Enter로 선택하고 선택한 영역 제목으로 포커스를 이동한다. 카드 선택·설명 열기만으로 방은 생성되지 않는다.
- 기존 전체 화면 모바일 튜토리얼, 게임별 옵션, 비회원 탐색/로그인 후 생성, 내가 연 게임방 링크와 링크·QR 초대 안내를 유지한다.
- 자유 대기실의 2명 설정에서 다른 게임으로 바꾸면 최소 3명으로 보정한다. 경매 선택·정원 변경 시 라운드가 정원보다 많도록 보정한다. 기존 서버 검증도 유지한다.

## 구현 위치

- `src/domain/game-catalog.ts`: 네 게임의 공개 탐색 정보·장르를 한 곳에서 관리.
- `src/components/game-cover.tsx`: 외부 이미지 요청 없이 아이콘·텍스트·CSS로 구성한 게임별 커버.
- `src/components/game-catalog.module.css`: 카드·검색·필터·상세·모바일 배치.
- `src/components/game-room-create.tsx`: 선택 상태와 기존 게임별 방 설정 연결.
- 기존 5개 브라우저 스크립트를 드롭다운 대신 카드 선택으로 수정했다. 새 게임은 서버 규칙/API 지원을 구현한 뒤 이 목록과 설정에 추가해야 한다.

- 기존 게임별 실제 SQL/SSE 브라우저 검사: 경매 5개, 자기소개 4개, 라이어 4개, 자유 대기실 14개 통과. QR·대기열·준비·진행·투표·정산·재접속을 포함한다.
- 실제 배포 번들의 미리보기·공개 화면 결과는 완료 후 아래에 기록한다. 실제 휴대폰 하드웨어 검사는 별도로 수행하지 않았다.

## 실제 공통 스타일과의 충돌 점검

첫 미리보기에서 `.participation-page label`이 검색 레이블의 방향을 세로로 바꾸고 여백을 추가하는 문제를 육안으로 확인했다. 게임 카드 검색의 방향/여백과 설정 폼의 레이블 간격을 범위가 좁은 선택자로 명시했다. 카드/상세 제목도 공통 제목 스타일과 분리했다. 소개 문구는 제시어 없는 클래식 방식도 포괄하도록 ‘정체를 숨긴 라이어’로 정리했다.

실제 SQL/SSE 검사에 `participation.css`와 실제 페이지 래퍼를 추가했고, 실제 번들 검사에서도 검색창의 가로 방향·높이와 설정 레이블 여백을 검증한다. 초기 후보 `20261031-game-catalog-01`은 운영으로 전환하지 않았다.
