# 홈 추천·인기·아카이브 개편

기준: 2026-10-25.

## 바꾼 부분

1. `곧 만나요`의 빈 목록을 실제 신청 가능한 예정 모집 + 기존 추천 모집으로 구성했다. 실제 모집을 우선하고 중복을 제거한 뒤 좋아요 순으로 정리한다. 기존 샘플은 샘플 표시와 예시 보기로만 소개한다. 실제 신청 가능 여부에는 참가·결제 예약과 정원 대기 안내 자리도 반영한다.
2. 추천 모임은 PC에서 사진/소개를 나란히, 모바일에서 세로 카드로 보여준다. 7초 자동 전환은 좌/상/우/하 방향으로 순환한다. 이전·다음·선택 점·일시정지, 터치 이동을 제공한다. 마우스·키보드 포커스·백그라운드·동작 줄이기 설정에서는 자동 전환을 멈춘다.
3. 인기 이야기에 오늘·이번 주·이번 달 세 탭을 제공한다. 한국 시간 0시/월요일 0시/매월 1일 0시부터 기준 시각까지의 실제 좋아요를 집계한다. 샘플·운영 제외 회원 반응·숨김을 기존 정책에 맞게 제외한다. 월간 필터는 더 보기와 주소/뒤로가기에도 유지한다.
4. 최근 완료 행사 기록 위치를 룰북·템플릿 홍보로 교체했다. 공개 발행된 아카이브의 요약·인원·시간·가격을 소개한다. 자료가 없으면 룰북 탐색·템플릿 탐색·첫 호스트 가이드를 안내한다. 유료 본문이나 비공개 자료를 홍보 카드로 가져오지 않는다.

## 현재 데이터와 원인

읽기 전용 확인 시 공개 모집 중 추천 샘플은 3개, 일정이 남아 열린 실제 모집은 0개였다. 이전 홈은 샘플을 제외한 예정 모집만 노출하여 비어 있었다. 기존 모집을 삭제하거나 날짜/모집 상태를 변경하지 않고 추천 동선을 복원했다.

Supabase 아카이브는 현재 자료가 0개다. 홈에는 탐색/가이드 홍보를 제공하며 공개 자료를 등록하면 실제 자료 카드로 자동 표시한다. 이전 로컬 자료를 임의로 복원하거나 새 운영 실적을 만들지 않았다.

- 전체 검사 1,021개 통과, 비밀값·서식·타입·Drizzle 검사 통과.
- 새 회귀: 한국 달력 월간 경계(연도 전환·윤년), 탭별 반응 범위, 숨김/샘플 제외, 추천 중복 제거·실제 모집 우선.
- 격리 브라우저: PC 9개 + Android 크기 9개 시나리오. 자동/수동 전환, 정지, 샘플 신청 제외, 월간 더 보기, 아카이브 미등록/등록 상태를 확인했다. 실제 사용자 데이터 변경 없음.
- 실제 로컬 홈에서도 PC/Android 크기의 페이지 오류·가로 넘침 0개, 기존 추천 콘텐츠와 아카이브 표시를 확인했다. 실제 휴대폰/Safari 검증은 아니다.
