# 게시판 제목·정렬과 거리순 개선

2026-10-30 · 최종 운영 릴리스 `20261030-story-controls-03`

- 홈 게시글 영역과 이야기 게시판 제목은 **전체 이야기**입니다. 상단 메뉴와 게시글 유형인 ‘이야기’ 값은 유지합니다.
- 정렬창은 실제 선택한 글자와 오른쪽 화살표를 4px 간격으로 가운데 배치합니다. 가장 긴 옵션 때문에 빈 공간이 생기던 문제를 없앴습니다. 네이티브 select를 유지해 모바일 선택창과 키보드 입력을 지원합니다.
- 웹 게임 상단 배지는 **베타**이며 기존 연한 글씨를 유지합니다. PC 상단 홈, 모바일 하단 홈도 유지합니다.
- **거리순**은 취향 필터와 독립적입니다. 이미 공유한 위치는 탐색 중 재사용하고, 브라우저 위치 권한이 허용되어 있으면 현재 위치를 바로 확인합니다. 나머지 환경은 사전 안내와 명시적 공유 버튼을 거칩니다.
- 위치 공유를 취소·거절하거나 위치 조회에 실패하면 기존 정렬을 유지합니다. 늦은 위치 응답은 취소·다른 카테고리 이동·언마운트 후 적용하지 않습니다. Permissions API 조회를 지원하지 않는 브라우저도 명시적 공유 안내를 제공합니다.
- 현재 위치는 컴포넌트 메모리와 기존 거리 조회 API에서만 사용하고 프로필·주소창·브라우저 저장소에는 저장하지 않습니다. 거리순은 위치가 등록된 모집글을 직선거리로 정렬합니다.
