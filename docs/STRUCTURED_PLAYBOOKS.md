# 구조화된 룰북·이벤트 템플릿

기준일: 2026-10-09 · 프로젝트: C:\Sliper

## 읽는 화면

아카이브 상세, 과거 발행 버전, 실제 행사에 보존한 진행 가이드가 같은 운영 가이드 화면을 사용한다. 본문을 버전 이력·구매/연구·연결 정보보다 먼저 보여준다.

| 목차 탭 | 담는 정보 |
| --- | --- |
| 개요·기획 | 요약, 기준 행사의 진행자·날짜·시간·장소·참가 인원·참가비, 기획 의도, 컨셉·세계관, 팀 구성·승리 조건·이동 규칙, 전체 시나리오 |
| 미션·규칙 | 공통 규칙, 미션 이름·구역 검색, 일반/대결/특별 유형 필터, 개별 미션의 소개·제한 시간·규칙·진행 포인트·점수 |
| 타임라인·진행 | 준비/본행사/마무리 큐시트, 진행 시점·프로그램·세부 내용·메모, 진행자 가이드, 기존 라운드 타이머 |
| 준비물·예산 | 준비물 체크리스트, 예산 항목·세부 내역·원화 금액, 자동 합계·비중, 예산 메모 |

모바일은 가로로 넘기는 목차와 세로 큐시트를 사용한다. 미션은 개별 펼침 형태로 읽고, 탭은 방향키·Home·End로도 이동한다. 0원 예산은 비중을 계산하지 않고 —로 표시한다.

## 작성 방법

1. /archive/new?kind=template 에서 템플릿을 작성한다. 룰북도 상세 항목 추가로 같은 구조를 사용할 수 있다.
2. 기본 소개·공통 규칙·준비물·진행자 가이드와 항목별 운영 계획을 작성한다. 미션 최대40개, 큐시트·예산 각각 최대60개이며 추가·삭제·위아래 이동이 가능하다.
3. 코엑스 점령전 예시 불러오기 → 예시로 교체를 누르면 제공받은 13개 미션·9개 큐시트·2개 예산 항목을 폼에 채운다. 작성 중인 입력값을 교체하며 저장/발행을 실행하지는 않는다.
4. 초안 저장 후 내용·이용 조건을 검토하고 발행한다. 기존 자료는 자동으로 항목을 추론해 재작성하지 않으며, 편집 화면에서 새 정보를 보완한다.

코엑스 예시의 모집 목표20명과 작성자 입력 참가23명을 구분한다. 기준 행사 날짜2026-02-27,14:00~18:00,장소코엑스와 행사 참가비3,000원은 운영 예시다. 자료 배포 가격(예시0원) 및 예산9,000원과 별개이며, 새 모임을 개설할 때 일정·정원·참가비를 다시 설정한다. 23명을 인증 참가 실적으로 합산하지 않는다. 예산9,000원은 제공된 지원금2개 항목의 합계이며 전체 행사 비용 또는 인당 비용으로 단정하지 않는다.

## 저장·버전·권한

- 0055 마이그레이션이 sliper.library_entries에 선택 JSONB event_plan을 추가한다. 기존 자료는 NULL을 유지한다.
- eventPlan은 기획·미션·큐시트·예산을 정해진 스키마로 검증한다. 한국어 UTF-8를 포함한 전체 자료 입력은140,000바이트 이내이며, 서버 HTTP요청은 기존150,000바이트 한도를 유지한다.
- 발행 버전의 content, 비공개 draftContent, 파생 초안과 행사 개설 당시의 template_provenance.snapshot에 같은 구조를 보존한다. 다음 버전을 발행해도 이전 버전과 개설한 행사의 가이드는 변하지 않는다.
- 신규 데이터는 기존 유료 payload 경계 안에 있다. 구매 승인이 없는 사용자의 상세·버전·목록·다운로드에는 운영 계획을 전달하지 않는다. 무료로 발행하면 기존 무료 자료와 동일하게 비회원도 전문을 읽는다.
- 자료 목록/검색의 공개 요약에 미션·예산 전문을 추가하지 않는다. 숨김·차단·탈퇴·소유자 권한 검사도 기존 서비스 경로를 사용한다.
- 마크다운 다운로드에 모든 구조화 항목과 기존 시나리오·규칙·준비물·진행자 가이드·타이머를 함께 포함한다.

## 검증

- 전체 검사: 형식·TypeScript·728개 회귀/DB 검사·Drizzle 통과.
- 새 검사는 입력 한도·날짜/시간·금액, 비용 구분·비중, 다운로드, 비공개 초안, 유료 구매 승인/회수, 이전 버전·파생·행사 사본 보존을 확인한다.
- 실제 로컬 PostgreSQL/Next HTTP 검사1개: 초안 저장→수정→발행→비회원 무료 상세/버전→다운로드→상세 HTML. 테스트 자료는 종료 후 정리한다.
- 프로덕션 빌드 및 서버 trace89개 검사에서 오류0개를 확인했다.
- 0055는 로컬 DB에 적용했다. 원격 Supabase 적용 및 실제 모바일 터치·브라우저 시각 검증은 별도다.
