# 홈 참여 동선·모바일 찜·취향 설정 반영 기록

완료: 2026-11-06 (한국 시간). 적용 주소: https://sliper.kr

## 사용자에게 보이는 변경

- 왼쪽 자동 배너를 유지하고, 오른쪽은 참가자 ‘모임 둘러보기’와 호스트·기업 ‘모임 열기’로 구성했다. PC에서는 세로, 모바일에서는 나란히 배치한다.
- 모바일 공통 헤더에 찜한 모임을 추가하고 순서를 **찜한 모임 → 검색**으로 배치했다. 로그인 전에는 로그인 후 북마크한 모집글 목록으로 복귀한다. 개인 목록의 기존 서버 권한 검사와 캐시 제외 정책을 그대로 사용한다.
- 취향 설정의 기본 화면은 모임 종류·관심 분야·날짜를 순서대로 선택한다. 장소와 사전 참가비는 펼쳐서 설정한다. 다른 주제와 날짜·금액 직접 입력도 유지한다.
- 신청 가능한 모임 조건은 스위치로 제공한다. 내용을 스크롤해도 하단 ‘모임 찾기’ 버튼은 계속 보인다. 초기화는 초안만 변경하고 적용 전 닫기는 기존 조건을 유지한다.
- 기존 날짜·거리·금액 검증과 위치 사용 동의 흐름을 유지했다. 필터를 고르는 동안 추가 결과 집계 요청을 만들지 않았다.

## 배포

- 릴리스: `20261105-preference-ui-01`
- 직전 롤백본: `20261105-home-audience-01`
