# 게임별 초보자 안내와 연습 예시

2026-10-31 · 웹게임 `/games`

## 제공 위치

- 게임 생성: 선택한 게임의 한 줄 소개와 ‘설명·튜토리얼’. 게임·라이어 방식 선택에 따라 설명이 바뀐다.
- 참가/호스트 대기실: ‘게임 방법’에서 언제든 다시 볼 수 있다.
- 진행 중: 같은 버튼을 제공하고, 설명을 읽는 동안에도 게임이 계속 진행된다는 안내를 표시한다.
- 자동 팝업을 띄우거나 설명을 읽었다는 이유로 준비/시작 상태를 바꾸지 않는다.

## 안내 구성

목표 → 참가자/진행자 설명 전환 → 번호별 단계와 실제 누를 버튼 → 예시 연습 → 종료 조건 → 초보자 팁 → FAQ 순서로 배치한다. 모바일에서는 단계 번호를 한 줄로 줄이고 모달 내부를 스크롤한다. Escape·닫기·마지막 확인으로 닫고 기존 버튼에 포커스를 돌려준다.

- MBTI 자기소개: 본인 MBTI 입력·종료 후 공개, 상황 소개, 설명 중 미리 선택 가능/제출 불가, 전원 소개 후 제출, 2명 O·1명 X의 의미, 전원 정답 또는 마지막 라운드 종료.
- 제시어 라이어: 기본/다른 제시어·정체 비공개/정체 공개의 차이, 30초 설명, 기권을 포함한 시작 인원 기준 과반수, 잘못 지목해도 무탈락, 라이어가 공통 제시어를 마지막으로 맞히는 승리 조건.
- 수상한 경매장: 감정가와 낙찰가, 판매자 음수 잔액 허용, 구매자 보유 머니 한도, 마감 연장, 유찰 시 정확한 매입금 환급, 현금+물건 가치로 순위 계산.
- 자유 게임 대기실: 입장·닉네임·준비 확인, 진행자가 직접 미션과 규칙을 알려주며 자동 문제/점수/승패는 없다는 점.
- 기존 MBTI 위장 방: 실제 본인이 아닌 배정 성향을 연기한다는 점과 공통 MBTI 최종 추리까지 별도 안내.

대기자는 비공개 게임 뷰를 받지 않을 수 있으므로 모드가 확인되지 않으면 기본 모드라고 단정하지 않고 모드별 차이와 게임 화면 확인 방법을 안내한다.

## 연습 예시

- 자기소개: 세 사람의 가상 추리 결과를 열어 2명 O·1명 X 피드백의 뜻을 확인.
- 라이어/MBTI 위장: 시작 인원 6명의 3표와 4표를 눌러 과반수 미달/지목 확정의 차이 확인.
- 경매: 이번 차례 머니 50G·감정가 100G·매입 후 −50G를 기준으로 70/100/140G 낙찰과 유찰을 선택해 판매자 머니와 양측 손익을 계산. 유찰은 100G를 환급해 50G로 돌아간다.

연습은 가상 값과 컴포넌트의 로컬 상태만 사용한다. 실제 제시어·배정·감정가·지갑 데이터를 예시에 전달하지 않고 입찰/준비 API를 호출하지 않는다. 별도의 DB 조회·외부 API·마이그레이션을 추가하지 않는다. 기존 마이그레이션 78개 유지.

- 운영 릴리스 `20261031-game-tutorial-01`. 소스 643파일. DB·인증 설정·게임 규칙 변경이나 마이그레이션 추가 없음, 기존 78개 유지.
- 전체 검사 **1,157개 통과**: 비밀정보·포맷·타입·전체 테스트·Drizzle 일관성.
- 전용 실제 SQL/SSE 브라우저 검사 5개, 기존 자기소개·라이어 브라우저 각 4개 통과.

## 모바일 잘림 개선 (2026-10-31)

공통 모바일 `.dialog-content`의 `bottom: 0`이 튜토리얼의 `top: 50%`·중앙 변환과 함께 적용돼, 320×568 화면에서 실제 읽기 영역이 76px로 축소되는 문제를 재현했다. 기존 화면 범위 검사만으로는 본문이 얼마나 보이는지 검증하지 못했다.

- 모바일에서는 중앙 모달을 전체 화면 안내로 전환하고, 모든 방향의 위치·변환·높이를 명시한다. 높이는 `100dvh`로 브라우저 도구막대 변화에 대응하고 `100vh` 대체값도 둔다.
- 제목과 닫기 버튼은 상단에 유지하되 소개 문장·조건 배지는 본문으로 옮겨 낮은 화면에서도 읽기 공간을 확보한다. 닫기 터치 영역은 44×44px 이상이며 기기 안전 영역을 반영한다.
- 설명·FAQ·팁의 모바일 본문 크기를 확대하고, 하나의 본문 스크롤로 마지막 안내까지 읽도록 한다. PC는 기존 중앙 배치와 단계 구성을 유지한다.
- 격리 SQL/SSE 브라우저 검사에 실제 사이트 공통 CSS와 짧은 화면·가로 화면의 본문 높이·마지막 문단 접근·닫기 영역 검사를 추가했다. 전용 검사 6개와 전체 검사 1,157개가 통과했다.

운영 릴리스 `20261031-game-tutorial-mobile-01`로 반영했다. 미리보기와 공개 주소에서 각각 40개 조합을 통과했다. 320×568, 360×640, 393×660, 412×915, 667×375, 844×390, 720×500, 721×500, 1440×900과 200% 글자 확대를 확인했다. 안내를 연 상태의 화면 높이 변경, 마지막 문단 접근, 가로 넘침 방지, 닫기와 원래 버튼으로 포커스 복귀도 검사했다. 실제 운영 게임은 생성하지 않았다. 작은 화면의 본문 높이는 76px에서 512px로 개선됐다.

Linux 빌드·trace 128개와 standalone 금지 파일/예상 밖 링크 검사를 통과했다. Sliper 웹만 전환했고 알림·영상 워커, 감시·TLS·Nginx·기존 사이트는 정상 상태로 유지했다. 신규 빌드 캐시를 제외했으며 기존 릴리스는 삭제하지 않았다. 최종 디스크 48%, 공개 health HTTP 200을 확인했다. 실제 휴대폰 하드웨어 검증은 별도로 수행하지 않았다.
