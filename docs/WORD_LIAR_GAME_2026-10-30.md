# 제시어 라이어 게임

2026-10-30 · `/games` · 릴리스 `20261030-word-liar-01`

기존 MBTI 자기소개 게임을 유지하고, 별도 ‘제시어 라이어 게임’을 추가했습니다. 새 방을 만들 때 게임·제시어 카테고리·라이어 방식을 선택합니다.

## 카테고리와 모드

음식, 동물, 장소, 직업, 사물, 스포츠·취미, 자연, 예능·게임의 8개 카테고리를 제공합니다. 각 20개, 총 160개 제시어가 서버의 `src/server/word-bank.ts`에 정의되어 있습니다. 클라이언트 번들이나 방 응답에 전체 목록을 싣지 않습니다.

- 기본 라이어: 일반 참가자들은 같은 제시어를 받습니다. 한 명의 라이어는 제시어 없이 ‘라이어’라는 안내만 받습니다.
- 다른 제시어 · 정체 비공개: 한 명만 같은 카테고리의 다른 제시어를 받고 라이어 여부를 알려주지 않습니다.
- 다른 제시어 · 정체 공개: 다른 제시어와 함께 본인이 라이어인지 안내합니다.

각 모드는 최소 3명·최대 30명으로 플레이합니다. 호스트는 진행 전용이며 참가자는 닉네임과 준비만 필요합니다. 개인 MBTI 입력은 요구하지 않습니다. 링크·QR과 선착순 대기열은 기존 기능을 사용합니다.

## 진행과 승패

1. 호스트가 시작하면 서버가 공통 제시어·라이어·다른 제시어를 무작위 배정합니다. 기본 모드의 라이어는 다른 제시어를 받지 않습니다.
2. 본인 카드에서 제시어/정체를 확인하고 다시 가릴 수 있습니다. 호스트는 시작 전·진행 중 정답을 받지 않습니다.
3. 순서대로 30초씩 제시어의 특징·경험을 설명합니다. 설명 질문은 차례 묶음마다 바뀌지만 같은 게임의 배정은 유지합니다.
4. 각자 의심되는 다른 참가자 한 명을 지목하거나 기권합니다. 전체 시작 인원의 과반수로만 확정합니다. 전원이 투표하면 자동 집계하고, 호스트는 미투표를 기권으로 처리할 수 있습니다.
5. 과반수가 없거나 일반 참가자를 지목하면 탈락 없이 다음 설명·투표로 이어집니다.
6. 라이어를 찾으면 정체만 공개하고 공통 제시어는 숨깁니다. 라이어만 최종 정답을 한 번 직접 입력합니다.
7. 정답이면 라이어, 오답이면 일반 참가자가 승리합니다. 결과 화면에서 공통 제시어·마지막 답을 공개합니다. 위장 모드는 라이어의 다른 제시어도 함께 공개합니다.

정답 비교는 유니코드 NFKC·띄어쓰기·대소문자를 정규화한 정확한 문자열 비교입니다. 동의어를 자동 판정하지 않습니다. 예: ‘고요 속의 외침’과 ‘고요속의외침’은 같은 답입니다. 정답 입력에는 기존 텍스트 정책 검사와 길이 제한을 적용합니다.

호스트가 재준비하면 같은 카테고리와 모드를 유지하고 새로 배정합니다. 게임 중단은 정답을 공개하지 않습니다.

## 저장·권한·비용

기존 `game_rooms.mbti` JSONB 상태와 투표·최종 추리 엔진을 확장했습니다. 카테고리·모드만 추가하고, 자기소개 상태와 별도로 동작합니다. SQL 테이블·열·마이그레이션·키·외부 서비스를 추가하지 않았으며 마이그레이션은 77개를 유지합니다.

기존 방 행 잠금 안에서 배정·투표·승패를 처리합니다. 일반 참가자는 본인 제시어만 받고, 호스트와 대기자·미입장자·퇴장자에게 비공개 답을 주지 않습니다. 기본 모드의 라이어에게 공통 제시어를 주지 않습니다. 기존 RLS·브라우저 역할 직접 접근 차단·서명 기기 쿠키·요청 제한·SSE/Supabase 갱신 힌트를 재사용합니다.

## 검증

- 전체 검사 1,142개 통과, 타입·포맷·비밀정보·Drizzle 일관성 확인.
- 격리 SQL 게임 검사 26개: 카테고리별 20개/중복 없음, 세 모드 배정·정체 노출, 호스트/대기자 차단, 직접 추리·띄어쓰기·승패·초기화 등을 포함합니다.
- 실제 SQL/SSE와 호스트/참가자 4개 브라우저의 라이어 흐름 4개 통과. 참가자 카드·투표·최종 입력·결과와 모바일 너비를 확인했습니다.
- 기존 자기소개 게임의 실제 SQL/SSE 5개 브라우저 회귀 4개 통과.
- Linux 운영 빌드·trace 128개·standalone 파일/링크 검사 통과. 실제 모바일 하드웨어의 추가 수동 플레이는 수행하지 않았습니다.
- 운영 화면 검사는 합성 참가자 응답을 사용해 실제 게임방이나 참가 기록을 생성하지 않습니다. 실제 게임 규칙과 전송은 격리 SQL/SSE 브라우저 검사에서 확인했습니다.

운영 미리보기·공개 도메인의 최종 화면 점검과 배포 결과는 `.local/ncloud-deployment-status.json`의 `wordLiarGame`에 기록합니다.
