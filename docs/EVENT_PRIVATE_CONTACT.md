# 참가자 전용 행사 연락처

2026-10-16 구현. 주최자가 행사 관리의 **담당자 연락처 설정**을 눌러 전화번호·이메일·HTTPS 문의 링크 중 하나와 안내를 직접 등록합니다. 프로필 전화번호와 기존 모집글 공개 문의 안내는 자동으로 복사하지 않습니다.

## 이용 동선

확정 참가자는 내부/외부 신청 상세 또는 공지방에서 **담당자에게 문의하기**를 눌러 확인합니다. 지정 담당자도 열람할 수 있고 등록·수정·공개 중단은 주최자만 할 수 있습니다. 닫힌 모달에는 값을 남기지 않으며 열린 화면은 15초·재활성화 때 권한을 다시 확인합니다.

주최자는 내 행사 관리에서 연락 방법을 고치거나 공개를 중단할 수 있습니다. 동시 편집은 버전으로 확인하고 오래된 수정은 거절합니다. 충돌 시 작성하던 값은 보존하고 최신 값 불러오기를 제공합니다.

## 권한과 보관

- GET/PUT/DELETE `/api/participation/events/{postId}/private-contact`는 모두 private/no-store 응답입니다. 변경은 같은 사이트의 요청만 허용합니다.
- 현재 활동 중인 주최자·지정 담당자 또는 확정 신청과 유효 공지방 멤버십을 동시에 가진 참가자만 조회합니다.
- 비회원·일반 외부 회원·결제/승인 대기·미확인 참가자는 열람할 수 없습니다. 담당자 해제, 참가 취소·환불 후 접근을 회수합니다.
- 글 삭제·운영 숨김·주최자/열람자 계정 제한·탈퇴·주최자와 양방향 차단도 확인합니다. 모집 마감은 열람 해제 사유가 아닙니다.
- 행사 자체 취소 후에도 아직 확정 상태인 참가자는 환불 문의를 위해 확인할 수 있습니다.
- `event_private_contacts`는 별도 서버 전용 테이블로 RLS를 적용하고 PUBLIC/anon/authenticated 직접 접근을 회수합니다.
- 응답에 주최자의 계정 ID·프로필 ID·닉네임·사진·수정자 ID를 덧붙이지 않습니다. 익명 행사도 ‘행사 담당자’로 표시합니다.
- 공개 글·목록·검색·공유·일반 행사 개요·알림·Redis에는 포함하지 않고 클릭 뒤 별도 인가 API로만 조회합니다.
- 공개 중단은 버전만 남긴 빈 행으로 처리하여 이전 편집이 값을 복구하지 못하게 합니다. 정상 탈퇴에서도 같은 트랜잭션으로 연락 값·안내·수정자를 제거합니다.

이미 본 연락처를 상대방이 별도로 보관하는 것까지 회수할 수는 없습니다. 본인이 제공할 수 있고 행사 운영에 필요한 연락 방법만 등록합니다. 별도 1:1 메신저 기능은 추가하지 않았습니다.

마이그레이션은 추가 `0066_event_private_contacts.sql`입니다. 같은 마이그레이션에서 기존 트리거 함수의 불필요한 공개 EXECUTE도 회수하며 이전 SQL은 변경하지 않습니다.

## 검증

입력 정규화·소유권·확정/유효 멤버십·취소/환불·차단/숨김/계정 제한·탈퇴 개인정보 삭제·수정 버전·브라우저 DB 접근 차단을 서비스 회귀로 검사합니다. 실제 HTTP는 `tests/event-contact-api.integration.ts`에서 공개 API/SSR 비노출·HEAD·CSRF·CRUD·버전·권한 회수를 확인하고 임시 데이터와 기존 프로필 상태를 보존합니다. 실제 Android/iPhone 직접 조작은 별도입니다.

최종 로컬 검증: 서비스 12개(전체945개에 포함), 실제 HTTP 신규1개(행사/안전 회귀 전체7개에 포함), Chrome PC·360px LAN6개 동작, 운영 빌드와 trace109개·오류0개를 통과했습니다. Chrome 기기 에뮬레이션과 실제 Android/iPhone 직접 확인은 구분합니다.
