## 검증과 보존

- 공식 npm run check에서 기존 파일5개의 줄바꿈 서식을 정리했다. 기능 변경은 없으며 환경 파일과 개인 도구 권한 설정은 제외한다.
- Git에 고정한 커밋으로 허용된 소스·자료·스크립트·마이그레이션만 패키징한다. 비밀값 검사·파일 해시·Linux 빌드·standalone 비공개 파일 검사를 완료한 뒤 전환한다.
- 기존 DB·인증·Storage·Redis·지도·메일 설정은 유지한다. 이번 운영 차이에 DB/워커 변경은 없어 DB 마이그레이션을 재실행하거나 워커를 중복 실행하지 않는다.
- 기존 영상·알림·그림·타운 워커는 실행 경로와 소스를 확인해 유지한다. 새 웹을 루프백 미리보기에서 점검한 뒤 웹만 전환한다. 실패 시 이전 current로 복구한다.
- 현재 사용 중인 릴리스와 직전 정상본은 삭제하지 않는다. 새 빌드에서 생긴 컴파일 캐시/임시 미리보기만 정상성 확인 뒤 정리한다.
- 브라우저 검사는 읽기 전용으로 실시하고 신규 QA 회원·방·업로드를 만들지 않는다.
