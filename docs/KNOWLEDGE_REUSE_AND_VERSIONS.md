# 운영 지식 재사용과 자료 버전

기준일: 2026-10-07. 성숙화 계획의 **2단계**를 구현했다. 룰북과 이벤트 템플릿은 통합 아카이브의 자료 종류로 유지하며, PostgreSQL을 초안·발행 버전·출처·행사 운영 사본의 원본으로 사용한다. Redis에 자료나 기록을 저장하지 않는다.

## 사용 순서

1. 주최자가 완료 행사 기록에 기획 의도와 실제 진행을 저장한다.
2. 기록 상세의 ‘회고로 템플릿 만들기’로 자신의 비공개 초안을 생성한다. 같은 기록에서 다시 누르면 기존 자료를 연다. 최신 회고를 바탕으로 만드는 요청만 허용한다.
3. 아카이브 편집에서 인원·시간·준비물·진행 구성을 보완하고 이용 조건을 적는다.
4. 변경 요약과 공개 동의를 확인한 뒤 첫 버전을 발행한다. 초안 저장만으로는 공개하지 않는다.
5. 이후 편집은 새 초안으로 저장한다. 공개된 v1은 유지되고, 발행 시 v2와 변경 요약을 추가한다.
6. 자료 상세의 발행 이력에서 이전 버전을 열람한다. 파생 허용과 열람 권한을 모두 충족한 버전을 선택해 자신의 초안을 만들 수 있다.
7. 발행 자료로 행사를 개설하면 그 발행 버전과 당시 이용 조건을 행사 진행 가이드에 고정한다. 자료 수정 이후에도 개설 당시 내용이 남는다.

새 자료도 편집 화면에서 초안 저장과 발행을 구분한다. ‘내 자료’에는 본인의 비공개 초안이 포함되고, 일반 목록·검색·포트폴리오에는 발행 자료만 제공한다.

## 회고에서 옮기는 내용

기획 의도·실제 진행·잘된 점·개선점만 가져온다. 일반 본문 문서, 사진, 업로드 영상, 외부 영상 삽입, 참가자 명단·연락처·신청 답변, 인증 후기와 기존 유료 자료 전문은 자동 복사하지 않는다. 회고의 기록 ID는 출처 관계로 저장한다.

인원은 초안 기본값이고, 진행 시간은 보존한 행사 일정에서 계산한다. 발행 전에 작성자가 실제 운영 조건을 확인해야 한다. 주최자 본인만 변환할 수 있으며 지정 담당자의 기록 열람 권한은 변환 권한을 부여하지 않는다.

회고에서 만든 템플릿은 원본 룰북의 복제 기능과 구분된다. 원본 룰북·템플릿 전문을 재사용하는 ‘파생 자료 만들기’는 선택한 발행 버전의 조건을 확인하는 별도 흐름이다.

## 권한과 이용 조건

- 비공개 초안은 작성자만 읽고 편집한다. 다른 사용자에게는 존재를 노출하지 않는다.
- 발행본은 기존 아카이브 정책대로 요약을 공개한다. 유료 전문은 작성자 또는 구매 승인 회원만 제공한다.
- 과거 발행본의 가격으로 전문 열람을 판단한다. 현재 자료가 무료여도 과거 유료 버전이 자동으로 열리지 않는다.
- 파생·상업적 사용 허용은 기본값이 모두 false다. 출처 링크만으로 재배포나 유료 운영 권한이 생기지 않는다. 행사 개설 시 유료 운영 조건도 확인한다.
- 파생 자료 발행 때 원본 열람권·파생 조건을 다시 확인한다. 원본보다 넓은 상업적 허용 조건을 부여할 수 없다.
- 차단·회원 이용 제한·탈퇴·운영 숨김을 자료 상세, 버전, 다운로드, 파생, 신규 행사 개설에 적용한다.
- 행사 기록은 회원 전용이다. 자료가 공개되어도 기록 출처 ID/링크는 해당 기록을 읽을 수 있는 회원에게만 반환한다. 비회원에게 원본 기록의 제목이나 미디어를 포함하지 않는다.
- 운영 숨김된 기록에서 새 버전을 발행하는 경로도 차단한다. 이미 발행한 자신의 자료 내용과 원본 기록 접근 권한은 별도다.

구매 승인과 외부 결제 확인은 기존 기능을 사용한다. 실제 자료 판매 웹훅·법적 이용약관·분쟁 처리·외부 거래 연동은 이후 시장/실서비스 단계에서 다룬다.

자료 사용 집계도 완료 확인을 기준으로 한다. 종료 시각만 지났거나 참가 전적만 기록된 행사는 집계하지 않으며, 취소·샘플·미참석·운영 숨김과 행사 주최자의 차단/계정 제한을 반영한다. 다운로드에도 현재 버전과 이용 조건, 권한에 맞는 원본 링크를 함께 표시한다.

## 데이터와 일관성

| 저장 항목                                 | 역할                                                                          |
| ----------------------------------------- | ----------------------------------------------------------------------------- |
| library_entries                           | 현재 발행본, 작성자만 보이는 draft_content, 최신 published_version, 고정 출처 |
| library_versions                          | 불변 전문·이용 조건·변경 요약·발행자·시각·버전 번호                           |
| source_version_id                         | 복제한 원본의 정확한 발행 버전                                                |
| source_record_post_id                     | 자신의 완료 행사 회고 출처                                                    |
| template_provenance.version_id / snapshot | 행사 개설 당시 자료 버전과 운영 사본                                          |
| event_records.snapshot.template           | 완료 시 자료 ID·제목·당시 버전 연결                                           |
| event_record_links                        | 회고에서 만든 자료와 관련 기록 연결                                           |

발행은 자료 행 잠금과 정확한 수정 시각을 사용하여 새 버전 삽입·현재 발행본 교체·초안 정리를 한 트랜잭션으로 처리한다. 같은 수정 버전으로 동시에 발행하면 한 요청만 성공하고 다른 요청은 CONFLICT다. 자료별 버전 번호와 기록별 작성자 초안에 DB 고유 제약을 적용한다.

DB 트리거는 발행 내용·버전 번호·출처·발행 시각과 행사 운영 사본의 수정을 막는다. 회원 탈퇴 시 발행자의 내부 ID를 비우는 FK 처리는 허용한다. 외부 원본/기록 연결을 이후 수정에서 교체할 수 없다.

기존 자료는 도입 시점의 현재 내용을 ‘기존 자료 기준본’으로 저장한다. 실제 과거 발행일이나 이전 변경 내용을 만들어내지 않는다. 기존 행사 진행 사본에는 버전을 추정하여 연결하지 않으며 ‘버전 기록 이전 자료’로 표시한다. 새 행사부터 정확한 버전으로 연결한다.

## API

| 메서드와 경로                             | 동작                                                               |
| ----------------------------------------- | ------------------------------------------------------------------ |
| POST /api/records/{postId}/template-draft | 최신 수정 시각을 확인한 주최자의 회고 → 비공개 템플릿              |
| POST /api/library/drafts                  | 원본 없는 비공개 자료 초안                                         |
| PUT /api/library/{id}/draft               | content, expectedUpdatedAt으로 초안 저장                           |
| POST /api/library/{id}/publish            | expectedUpdatedAt, changeSummary, publicContentConsent:true로 발행 |
| GET /api/library/{id}/versions?page=1     | 20개씩 발행 이력                                                   |
| GET /api/library/{id}/versions/{number}   | 선택 버전의 접근 권한을 확인한 본문                                |
| POST /api/library/{id}/derive             | version으로 원본을 선택하고 파생 초안 생성                         |
| POST /api/library/{id}/host               | 현재 불변 발행본으로 행사 개설                                     |

현재의 목록·상세·구매 승인·다운로드 API를 유지한다. 기존 직접 수정 API는 출처 없는 발행 원본에만 허용한다. 비공개 초안과 기록/버전 파생 자료는 공개 동의가 필요한 발행 API를 거쳐야 한다. 새 화면은 초안/발행 API를 사용한다. 쓰기는 동일 출처와 입력값·수정 버전을 검증하고 응답은 private/no-store다.
