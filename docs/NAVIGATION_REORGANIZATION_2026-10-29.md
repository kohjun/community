# 메뉴·탐색 동선 통합 — 2026-10-29

운영 사이트 https://sliper.kr 에 반영했다. 상단 메뉴를 홈 / 이야기 / 번개 모임 / 이벤트 맵 / 아카이브 / 플레이어·크루의 6개로 정리했다.

## 새 위치

| 기존 메뉴 | 새 위치                                           | 주소                              |
| --------- | ------------------------------------------------- | --------------------------------- |
| 내 행사   | 마이페이지 → 내 행사 → 신청·참가한 행사           | `/mypage?tab=events`              |
| 행사 관리 | 마이페이지 → 내 행사 → 운영·관리하는 행사         | `/mypage?tab=events&view=hosting` |
| 통합 검색 | 기존 검색창의 통합 버튼과 공통 헤더의 검색 아이콘 | `/search`                         |
| 주제 탐색 | 통합 검색의 ‘주제별로 둘러보기’                   | `/search#topics`                  |
| 행사 기록 | 아카이브 → 행사 기록 탭                           | `/archive?tab=records`            |

아카이브는 전체 자료 / 룰북 / 이벤트 템플릿 / 행사 기록으로 구분한다. 마이페이지는 프로필·활동 / 내 행사로 나누고, 내 행사 안에서 참가자와 주최자 기능을 구분한다. 주제 탐색은 검색어가 없어도 확인할 수 있으며, 검색 결과에서도 주제 안내로 이동할 수 있다.

## 기존 링크와 권한

- `/topics`, `/records`, `/management`, `/participation` 목록 주소는 새 위치로 HTTP 308 이동한다.
- `/topics/{slug}`, `/records/{행사ID}`, `/records/{행사ID}/edit`, `/management/events/{행사ID}` 상세 주소는 유지한다.
- 자료에서 이동하는 행사 기록의 `libraryId` 조건을 보존한다.
- 행사 기록의 회원 열람 권한과 본인 행사 관리 권한은 기존 서비스에서 계속 검사한다. 비회원에게는 로그인 후 돌아올 위치를 전달한다.
- 목록을 합친 것은 탐색 동선이며, 자료의 구매·열람 권한이나 기록 발행 정책을 변경하지 않았다.
- PC·모바일의 메뉴 선택 표시, 탭 이동, 뒤로/앞으로 가기를 함께 반영했다.
