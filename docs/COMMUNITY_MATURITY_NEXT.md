# 커뮤니티 성숙화 보완 계획
기준: 2026-10-18. 기존 데이터와 신청·결제·공지방·자료 권한을 보존한다.

## 이번 구현 순서
1. 첫 참가 안내: 초보/혼자 참여, 분위기, 활동량, 현장 비용 예상 범위, 공개 만남 안내, 준비물. 번개 개설/행사 설정에서 저장하고 직접/외부 신청 화면에서 표시. 기존 행사는 미입력으로 유지. 안내 수정 충돌 방지.
2. 주제 운영: 기존 3개 주제에 입문 가이드·질문 발제·자료 탐색 연결. 주최자 3~5명/지역 1곳/취향 2~3개/4주 운영 계획 작성·내보내기, 크루·행사 관리·회고·재개최의 기존 경로 연결. 실제 모집·주최자 섭외·지역 선정·주간 발행은 운영자가 실행.
3. 설명 가능한 신뢰: 기존 매너온도 계산 유지. 공개 동의에 맞는 계산 근거, 신규/비공개 구분, 점수와 안전 보장 구분, 정정 요청 동선. 평가자 및 비공개 전적을 추론할 정보 추가 금지.
4. 실행하는 아카이브: 초보 호스트 가이드와 조건별 추천 탐색, 접근 가능한 자료의 준비 순서·큐시트 인쇄, 준비물·규칙 누락 안내. 실제 사용과 작성 예시 구분. 유료 본문 권한 우회 금지.
5. 체감하는 운영: 신고/문의 현재 상태의 의미·다음 행동·접수 시각 안내, 연락 두절/기록 정정 문의 도움말. 실제 내부 검토 시작을 추측하거나 처리시간 보장 금지.
6. 회귀 검사·타입·빌드·모바일 점검과 결과 문서.

## 선택한 주석의 후속 범위
- 아카이브 가이드/운영 사례 및 신뢰 정보는 위 3~4에서 직접 보완.
- 조건별 모집 알림은 기존 관심사/호스트 구독을 유지하며 별도 후속 작업: 저장 조건, 매칭 시각, 중복 방지, 알림 빈도/취소, 현재 콘텐츠 접근 권한 검증.
- 정원 대기는 별도 후속 작업: 대기 등록/취소, 자리 알림, 만료, 담당자 승인 시 정원 잠금. 기존 승인 대기를 정원 대기로 표시하지 않음.
- 사용자가 우선 지정한 1·4·5·6 보완을 먼저 완료한 뒤 위 후속 작업의 범위를 보고한다.
- 미래 기능(행사 시리즈/포트폴리오 내보내기/AI)은 이번 요청에서 구현하지 않고 보완 결과 확인 후 논의.

## 초기 운영안
준비 주: 한 지역과 취향 2~3개 선정, 주최자 3~5명 동의 후 크루 구성, 주최/현장보조/문의담당 배정.
1주: 소규모 첫 행사. 처음 온 사람의 질문 수집, 담당자 출석 확인.
2주: 1주 질문을 입문 안내에 반영. 동일 형식 두 번째 행사에서 개선점 한 가지 검증.
3주: 다른 주최자가 자료를 재사용, 실제 사용 버전과 운영 차이 기록.
4주: 완료·후기·회고와 재참가 경험을 검토하고 다음 달 유지/변경 결정.
각 회차: 모집 → 승인 → 공지 → 참가 확인 → 완료 → 회고/후기 → 개선점 1개 → 다음 회차.
운영 문서의 인원과 기간은 시작 제안이며 실제 회원/지역/행사를 생성하거나 섭외한 결과가 아니다.

## 검증 기준
입력 검증/비소유자 거절/기존 안내 보존/충돌409/안내에 대한 콘텐츠 필터/과거 행사 무변경.
신규/비공개 프로필에서 참가 횟수 추론 방지, 기존 온도 값 유지.
접근권한 없는 자료 본문은 준비 도구/인쇄에 포함되지 않음.
실제 운영 상태만 표시, 승인 대기와 결제/정원 대기 혼동 금지.


## 구현 및 검증 결과 — 2026-10-18

- 첫 참가 안내를 번개 개설·행사 설정에서 입력하고 내부/외부 신청 화면에 표시한다. 초보/혼자 참가, 분위기·활동량, 현장 비용 범위, 만남 안내·준비물을 저장하며 미입력과 명시적 0원을 구분한다. 소유자 권한·내용 정책·수정 버전 충돌을 검사한다.
- Supabase에 `0069_participant_guidance`를 적용했다. 원장은 70개이며 기존 행사 설정의 값이 유지됐음을 비교했다. 기존 행사는 안내 미입력으로 남기고, RLS 및 anon/authenticated의 직접 테이블 조회 차단을 유지했다.
- `/hosting-guide`에 지역·주최자 목표·주제를 선택하는 4주 운영 계획과 Markdown 다운로드를 제공한다. 입력은 서버에 저장되는 운영 그룹이 아니며, 실제 섭외·담당 배정·행사 생성·주간 발행은 운영자가 기존 크루/행사/기록 화면에서 실행한다.
- 주제 페이지에 입문 안내·질문 발제·미답변 이야기·준비 자료 연결을 추가했다. 기존 회고와 인증 후기 동선을 통해 다음 회차 개선에 활용한다.
- 플레이어에 기존 매너온도의 계산 근거와 기록 정정 경로를 표시한다. 신규와 비공개 전적을 구분하며 비공개 참가 횟수는 추가 노출하지 않는다. 기존 점수 계산은 변경하지 않았다.
- 아카이브에 첫 진행자를 위한 조건별 탐색, 열람 가능한 자료의 준비 체크리스트와 준비물·큐시트 인쇄를 제공한다. 체크 상태는 현재 화면에서만 유지되며, 유료 자료 권한을 새로 부여하지 않는다.
- 신고·문의에 실제 접수/답변/처리 상태의 의미와 다음 행동을 표시하고, 첫 참가·연락 두절·기록 정정 도움말을 보완했다. 내부 검토 시작 또는 처리 기한을 추정해 표시하지 않는다.

### 확인한 항목

- `npm run check`: 전체 1,007개 테스트 통과, 비밀값 검사·서식·타입·Drizzle 검사 통과.
- 참가 안내 포함 번개 집중 검사: 16개 통과. 기존 안내 보존, 미소유자 거부, 동시 편집 충돌, 비용 범위 검증, 콘텐츠 정책, 명시적 삭제를 확인했다.
- 브라우저 격리 검증: 데스크톱 7개 + Android Pixel 7 에뮬레이션 7개 시나리오 통과. 페이지 오류·가로 넘침·실제 사용자 데이터 쓰기 0개. 실제 휴대폰 검증은 아니다.
- 현재 소스와 동일한 격리 사본에서 운영용 Next.js 빌드 통과. 서버 추적 111개 검사에서 비밀 파일 및 영상 워커 의존성 오류 0개.
- 로컬 서버의 `/hosting-guide`, `/topics/mystery`, `/archive`, `/help` 모두 HTTP 200 확인.
- 배포 산출물은 개발용 의존성 연결을 제거한 뒤 별도 검사했다. 이 검증은 실제 Ncloud 배포, 운영 부하 시험, 실제 회원 신청 시나리오 검증을 대신하지 않는다.

### 남은 범위

- 저장한 상세 조건에 맞춘 모집 알림과 정원 대기 신청은 별도 후속이다. 기존 관심사/호스트 구독과 담당자 승인 대기를 유지한다.
- 지역 선정, 주최자 3~5명 섭외, 실제 회차 운영·후기 수집은 운영 실행이 필요하다. 이번 도구가 자동으로 운영 실적을 만들지는 않는다.
- 미래 기능 세 가지는 행사 시리즈, 포트폴리오 내보내기, AI 보조다. 이번 보완 후 목적·비용·우선순위를 사용자와 논의하고 구현 범위를 정한다.
