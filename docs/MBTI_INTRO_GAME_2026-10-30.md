# MBTI 자기소개·추리 게임

2026-10-30 · `/games` · 릴리스 `20261030-mbti-intro-01`

## 확정 규칙

- 새 방의 기본 게임은 ‘MBTI 자기소개 게임’입니다. 라이어 안내·배정·투표는 사용하지 않습니다. 기존에 열린 라이어 방은 이용 시간 내 호환을 유지하며 새로 만드는 방에서 새 방식을 선택합니다.
- 로그인한 호스트는 진행만 담당하며 참가 정원에서 제외됩니다. 참가자는 QR/링크로 들어와 닉네임과 스스로 선택한 MBTI를 저장합니다. 저장 화면에서 게임 종료 후 이 방의 참가자·호스트에게 MBTI를 공개한다고 안내합니다. 사이트의 공개 프로필에는 연결하지 않습니다.
- 호스트가 1~10라운드를 선택하며 기본 5라운드입니다. 참가자는 최소 3명, 최대 30명입니다.
- 매 라운드 공통 상황을 보여주고 입장 순서대로 자신의 행동을 설명합니다. 본인의 ‘설명 완료’ 또는 호스트의 ‘다음 차례로’로 순서를 진행합니다. 경과 시간을 표시하지만 시간 경과만으로 발언을 강제 종료하지 않습니다.
- 설명을 듣는 동안에도 다른 참가자의 MBTI를 선택·수정할 수 있습니다. 선택은 제출 전까지 본인 화면의 임시 상태이며 단계·라운드 전환 시 유지합니다. 제출 전 새로고침에 대한 복구 보장은 없으며 마지막 제출 기록은 서버에 보관합니다.
- 전원의 설명이 끝나면 제출 버튼을 엽니다. 서버도 설명 단계의 제출을 거절합니다. 자신을 제외한 시작 참가자 모두에 대해 MBTI 한 개씩 입력해야 합니다. 중복·자신 포함·누락·다른 참가자 ID를 거절합니다.
- 한 사람의 네 글자가 모두 맞아야 정답 1명입니다. 제출 후에는 본인에게만 ‘2명 O · 1명 X’처럼 개수를 보여주고 누구를 맞혔는지는 공개하지 않습니다. 해당 라운드는 한 번만 제출할 수 있으며 이전 선택과 결과를 추리 기록에서 참고할 수 있습니다.
- 전원이 제출했지만 완벽한 정답자가 없으면 결과 확인 단계로 이동합니다. 호스트가 다음 라운드를 열면 새로운 상황과 첫 사람의 설명부터 다시 진행합니다. 호스트는 미제출자가 있을 때 확인 후 현재 라운드를 마감할 수 있습니다.
- 다른 참가자 전원을 맞힌 첫 제출이 서버에 확정되면 즉시 게임을 종료하고 승자와 시작 참가자 전원의 MBTI를 공개합니다. 동시에 제출해도 방 행 잠금으로 먼저 확정된 한 명만 승리합니다.
- 마지막 라운드까지 정답자가 없으면 정답자 없이 종료하고 전원의 MBTI를 공개합니다. 호스트의 ‘게임 중단’은 정답 공개 없이 종료합니다. 새 게임 준비 시 기존 MBTI 등록과 추리 기록을 초기화합니다.

MBTI 글자 뜻 도움말을 제공하며, 상대의 성격이 옳고 그른지를 평가하지 않습니다.

## 저장과 권한

`sliper.game_rooms.mbti_intro` nullable JSONB 열을 추가했습니다. 마이그레이션 `0076_mbti_intro.sql`, 누적 77개입니다. 기존 행의 내용·계정·스토리지 설정은 변경하지 않았습니다.

상태에는 자기 입력 MBTI, 시작 명단 사본, 현재 상황·발언 순서, 제출한 추리·정답/오답 수, 승자를 보관합니다. 서버의 기존 방 행 잠금 안에서 등록·설명 완료·제출·다음 라운드·종료를 처리합니다. 고정된 시작 명단으로 채점하며 대기자는 다음 게임까지 추리에 참여할 수 없습니다.

응답에는 본인 MBTI와 본인 제출 기록만 넣습니다. 호스트도 종료 전에는 다른 사람들의 MBTI를 받지 않습니다. 종료 결과일 때만 전체 답을 제공합니다. 대기자·미입장자·퇴장자에게 자기소개 상태를 반환하지 않습니다. 기존 RLS·브라우저 역할의 직접 테이블 접근 차단과 비회원 서명 쿠키·요청 횟수 제한을 유지합니다.

실시간 전송은 기존 Supabase 비공개 갱신 힌트와 각 참가자에게 권한을 적용한 SSE를 사용합니다. 제시어나 답을 공개 채널로 방송하지 않습니다. 별도 서비스·워커·비밀키는 추가하지 않았습니다.

MBTI의 입력·공개·보관 범위를 등록 화면과 개인정보 안내에 반영했습니다. 방 이용은 기존 24시간 제한을 사용하고 서버 자료의 물리 자동 파기는 이번에 추가하지 않았습니다.

## 검증

- 전체 검사 1,139개 통과, 타입·포맷·비밀정보·Drizzle 일관성 확인.
- 격리 SQL 게임방 검사 23개: 기존 게임 20개에 자기소개 등록·발언 권한·설명 중 제출 차단·2명 O/1명 X·중복/누락 제출·즉시 승리·라운드 상한과 공개·초기화 검사 추가.
- 실제 SQL/SSE와 호스트·참가자 5개 브라우저를 연결한 흐름 검사 4개 통과. 설명 중 선택, 단계 전환 시 유지, 개수 피드백, 새 설명 라운드와 최초 정답 종료를 확인했습니다.
- 기존 자유 대기실·QR 브라우저 회귀 14개 통과.
- Linux 운영 빌드·trace 128개와 standalone 파일·링크 검사 통과.
- 운영용 미리보기·공개 도메인은 실제 게임을 만들지 않는 합성 참가자 응답으로 UI를 확인합니다. 실제 SQL 규칙과 실시간 전송은 격리 브라우저에서 검증했습니다. 실제 모바일 하드웨어의 추가 수동 플레이는 수행하지 않았습니다.
