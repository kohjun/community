# 홈 글 목록 너비와 역할별 상단 메뉴 — 2026-11-19

## 요청과 구현

- 홈의 최근 올라온 글이 상위 모듈과 같은 너비를 사용한다. 홈 전용 .sl-layout--home에서 minmax(0,1fr)을 사용하고 공통 max-width·좌우 여백을 재사용한다. 이야기/카테고리 목록의 사이드바 배치는 유지한다.
- 참가자 상단: 이야기 → 이벤트·행사 → 번개·모임 → 웹게임 → 더보기. 더보기: 플레이어·이벤트 맵·모임 제안하기.
- 호스트 상단: 아카이브 → 크루 → 웹게임 → 이야기 → 더보기. 더보기: 호스트 가이드·모임 관리. 크루는 /players?tab=crews에 연결한다.
- PC·모바일에 같은 nav를 사용한다. 모바일은 기존 브랜드·보기 모드·검색/찜 행 아래에 탭 행을 추가한다. 로그인한 헤더 CSS에서도 보기 모드 중앙 배치를 유지한다. 기존 하단 메뉴는 보존한다.
- 이벤트·행사 필터에서 해당 탭의 aria-current를 표시하며 활성 탭은 색상과 밑줄로 구분한다.
- 더보기는 native popover를 우선 사용해 Escape·바깥 클릭·포커스 복귀를 브라우저에 맡긴다. 미지원 환경은 기존 방식의 작은 펼침 메뉴로 동작한다. 위치는 트리거 기준으로 계산하고 화면 안으로 제한한다. 화살표 키 앱 메뉴 역할은 적용하지 않는다.
