# 단서각 기본 문제 자료

사진20개는 Wikimedia Commons의 재배포 가능한 이용 조건을 확인했다. 원본 저작자·라이선스·출처는 `public/games/clue/ATTRIBUTIONS.json`에 보존하며 게임 화면에 표시한다. 좌표는 해당 장소의 대표 지점이며 촬영자 GPS를 뜻하지 않는다. 사진은 리사이즈·메타데이터 제거·WebP 변환했다. CC BY-SA 자료와 그 변환본에는 원본의 동일 라이선스가 적용된다.

소리10개는 Team Sliper가 직접 합성한 신호·효과음이다. 실제 생활 소리를 현장에서 녹음한 자료로 표시하지 않는다.
