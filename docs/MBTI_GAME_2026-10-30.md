# MBTI 위장 게임

2026-10-30 · 운영 릴리스 `20261030-mbti-game-01` · `/games`

## 플레이

1. 로그인한 호스트가 ‘MBTI 위장 게임’을 선택해 방을 만듭니다. 최소 3명, 최대 30명이며 호스트는 진행 전용입니다.
2. ‘정체 비공개’는 제시어만, ‘정체 공개’는 제시어와 본인의 라이어 여부를 알려줍니다. 기본값은 비공개입니다.
3. 참가자는 링크·QR로 로그인 없이 입장하고 닉네임과 준비를 완료합니다. 기존 선착순·대기열을 사용합니다.
4. 서버가 한 명의 라이어와 서로 다른 두 MBTI를 무작위 배정합니다. 실제 개인 MBTI는 수집하지 않습니다.
5. 모든 사람에게 같은 상황을 보여주고 입장 순서대로 30초씩 연기합니다. 10개 상황을 섞어 사용하고 이후 순환합니다.
6. 각 참가자는 다른 참가자 한 명을 선택하거나 기권합니다. 전원이 투표하면 자동 집계하며, 호스트는 확인 후 미투표를 기권으로 처리하고 집계할 수 있습니다.
7. 시작 참가 인원 전체의 과반수로만 지목합니다. 6명이면 4표입니다. 과반수가 없거나 일반 참가자를 지목하면 탈락 없이 다음 상황을 진행합니다.
8. 라이어를 찾으면 정체만 공개하고 공통 MBTI는 숨깁니다. 라이어가 한 번 추리해 공통 MBTI를 맞히면 라이어 승리, 틀리면 일반 참가자 승리입니다.
9. 결과 화면에는 공통 MBTI·라이어 제시어·마지막 추리와 승패가 표시됩니다. 호스트가 재준비하거나 방을 닫을 수 있습니다. ‘게임 중단’은 정답 공개 없이 종료합니다.

MBTI는 실제 성격의 평가 기준이 아닌 연기 제시어입니다. 표현의 정답을 판정하지 않습니다.

## 저장·권한·동시성

- 기존 `sliper.game_rooms`에 nullable JSONB `mbti` 열 하나만 추가했습니다. 기존 자유 게임방은 null이며 동작을 유지합니다. 마이그레이션 `0075_mbti_game.sql`, 누적 76개입니다.
- 비공개 배정·고정 참가자 명단·상황·투표·마지막 추리를 PostgreSQL에 저장합니다. 기존 방 행 잠금과 5초 statement timeout으로 배정·투표·집계·승패를 직렬화합니다.
- 일반 참가자에게는 본인 제시어·본인 투표만 전달합니다. 호스트에게 제시어와 숨은 정체를 주지 않으며 대기자·미입장자·퇴장자에게 MBTI 상태를 주지 않습니다. 공통 정답과 다른 제시어는 최종 결과에서만 함께 공개합니다.
- 각 상황 번호를 확인해 이전 상황의 늦은 투표를 거절하고, 중복 투표·비참가자 투표·라이어가 아닌 사람의 최종 추리를 차단합니다. 실제 시작 명단을 과반수의 고정 분모로 사용합니다.
- 30초 마감은 서버 시각 기준입니다. 타이머 마감 재조회와 기존 SSE·DB 재확인에서 차례 전환을 확정합니다. 클라이언트 타이머는 서버 시각으로 보정합니다. 별도 상주 타이머 워커는 추가하지 않았습니다.
- 기존 비공개 Supabase Broadcast는 방 UUID 갱신 힌트만 전송합니다. 제시어·투표는 방송하지 않고 각 요청의 권한에 맞는 SSE 스냅샷으로 제공합니다.
- 기존 RLS와 anon/authenticated의 직접 테이블 접근 차단을 유지합니다. 새 키·서비스·결제·개인 MBTI 입력은 없습니다. 방의 기존 24시간 이용 제한을 사용하며 물리 데이터 자동 삭제 기능을 새로 추가하지 않았습니다.

## UI와 검증

Pretendard·파란색을 유지합니다. PC는 공개 진행 화면 옆에 개인 카드를, 모바일은 위에 배치하고 제시어 확인·가리기를 지원합니다. 투표·최종 추리·결과를 단계별로 구분합니다.

- 전체 검사 1,136개·실패 0개, 타입·포맷·비밀정보·Drizzle 일관성 통과.
- 격리 SQL 게임방 검사 20개: 비밀정보 투영, 6명 과반수·오지목, 기권과 자동 집계, 최종 승패·권한·초기화 등을 포함합니다.
- 실제 SQL·SSE와 호스트/참가자 브라우저 4개를 연결한 MBTI 흐름 검사 4개, 기존 대기실·QR 회귀 14개 통과.
- 운영용 Linux 빌드와 trace 128개, standalone 파일·링크 검사 통과.
- 실제 모바일 하드웨어의 추가 수동 플레이는 수행하지 않았습니다. 자동 브라우저의 320·393·720·721·1440px 화면을 사용했습니다.
- Node SSR 검사에서 기존 CSS 모듈 로딩 문제를 발견해 테스트 전용 로더를 추가했습니다. 실제 CSS 배치는 브라우저에서 별도로 검증합니다.

최종 공개 도메인 화면 검사 결과와 파일 수는 `.local/ncloud-deployment-status.json`의 `mbtiGame`에 기록합니다. 운영 화면 검사에서는 합성 참가자 응답을 사용해 실제 게임방이나 참가 데이터는 만들지 않습니다. 게임 규칙·SQL·SSE의 실제 연결은 격리 브라우저 검사에서 검증했습니다.
